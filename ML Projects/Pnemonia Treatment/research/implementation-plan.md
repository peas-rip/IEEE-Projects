# Implementation Plan

## Scope and Non-Goals
**In scope:**
- Clean PyTorch implementation of PneumoNet-v1 and PneumoNet-v2 custom CNNs.
- Transfer-learning wrappers for VGG-16, Inception-v3, Xception, MobileNet-v2.
- Weighted ensemble logic for Stage 1 (Normal vs. Pneumonia) and Stage 2 (Bacterial vs. Viral).
- Data loading, preprocessing (resize 224x224, normalization, augmentation), and 80:20 split.
- Training pipeline (SGD, lr=1e-4, Categorical Crossentropy), checkpoint save/load.
- Evaluation (accuracy, precision, recall, F1, AUC, AP, confusion matrix, ROC).
- CLI entry point for train/evaluate/infer.
- Synthetic smoke-test fixture and unit/integration tests.
- README with verified quickstart commands.

**Non-goals:**
- Web UI, API server, database, Docker, cloud deployment (not required by the paper).
- Reproducing the exact paper metrics on the real Kermany dataset (data is gated behind author request); instead, validate on synthetic data and document paper-reported targets.
- Genetic-algorithm weight optimization (paper narrative only; implement grid search over weights as an optional tool if needed).

## Architecture and Data Flow
```
Input CXR (224x224x3)
   |
   v
[Preprocessing: resize, normalize, optional augmentation]
   |
   v
Stage 1 Ensemble (Detection: Normal vs. Pneumonia)
   - Base models: VGG-16, Inception-v3, PneumoNet-v1, PneumoNet-v2
   - Weighted average of softmax probabilities -> detection label
   |
   if Normal -> output "Normal", END
   if Pneumonia ->
   v
Stage 2 Ensemble (Classification: Bacterial vs. Viral)
   - Base models: Xception, MobileNet-v2, PneumoNet-v1
   - Weighted average of softmax probabilities -> bacterial/viral label
   |
   v
Output: Normal / Pneumonia-Bacterial / Pneumonia-Viral
```

## Dependencies (with justification)
- `torch >= 2.0`: model definitions, autograd, training (paper uses CNNs; PyTorch is standard and already installed).
- `torchvision >= 0.15`: transfer-learning backbones (VGG-16, Inception-v3, Xception, MobileNet-v2), image transforms.
- `scikit-learn >= 1.0`: train/test split, metrics (accuracy, precision, recall, F1, ROC/AUC), confusion matrix.
- `Pillow >= 9.0`: image loading and resizing.
- `numpy >= 1.20`: array operations.
- `matplotlib >= 3.0`: ROC and confusion-matrix plots.
- `pyyaml >= 5.0`: config file parsing.
- `tqdm >= 4.0`: training progress bars.

## Data and Configuration Management
- `configs/default.yaml`: hyperparameters (lr=1e-4, batch_size=32, epochs=10, image_size=224, ensemble weights, paths).
- Dataset path is configurable; no hard-coded absolute paths.
- Real dataset: obtain from corresponding author (paper Data Availability). Not shipped with repo.
- Synthetic fixture: generated by `make_synthetic_fixture()` for smoke tests.

## Test Strategy
- Unit tests: tensor shapes/dtypes, model output shape, loss behavior, data transforms, metric computation on hand-calculated examples.
- Integration tests: forward pass on tiny fixture, minimal training step, checkpoint save/load, config parsing, CLI entry point.
- Scientific validation: verify PneumoNet-v1/v2 architecture matches paper (filter counts, layer order); ensemble aggregation order matches paper narrative.

## Compute/Resource Estimate
- Smoke test (synthetic data): CPU, < 1 GB RAM, < 5 min.
- Small training run (real data subset): GPU 4 GB VRAM recommended, ~30–60 min.
- Paper-scale training: not feasible to verify without real dataset; documented as target.

## Risks and Blockers
| Risk | Impact | Mitigation |
|------|--------|------------|
| Real Kermany dataset not publicly downloadable | Cannot reproduce paper metrics exactly | Use synthetic fixture; document paper-reported targets as reference only |
| Exact ensemble weights unpublished | Cannot exactly match 98.03% / 91.93% | Grid search weights on validation split; label as INFERRED |
| Grayscale vs. 3-channel input ambiguity | Model input mismatch | Replicate grayscale to 3 channels; document assumption |
